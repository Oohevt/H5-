HTML 好用到难以置信，是一种新的 AI 输出格式。

当 Markdown 长文开始变得难读，可以让 AI 直接生成一个可打开、可阅读、可交互的单文件 HTML 页面。 html-effectiveness 的价值不只是示例本身，而是提醒我们：复杂内容可以被组织成网页，而不是只堆成文本。

核心判断

单文件 HTML 适合作为方案、报告、原型、复盘、流程图和研究解释的交付物。它既能本地打开，也能部署成公网链接。

01 / What

不是传统 App 工程

它更像一组 AI 生成的自包含 HTML 示例集，每个文件都能独立打开、独立阅读、独立分享。

02 / Why

比 Markdown 更适合复杂表达

当内容包含结构、对比、流程、交互、图形或演示节奏时，HTML 可以把信息层次做得更清楚。

03 / How

作为输出格式参考

以后遇到复杂需求，不只让 AI 写长文，也可以要求它生成一个单文件 HTML 可视化文档。

Use Cases

适合沉淀的页面类型

  • 项目介绍、产品方案、报价说明、汇报页
  • 研究报告、状态报告、事故复盘、流程解释
  • 临时 Demo、交互原型、小型编辑器和 Prompt 调试器
Rule

公开分享前先脱敏

如果页面要放到 GitHub Pages，就不要包含客户机密、API Key、账号密码或内部系统地址。

推荐使用方式

让 AI 根据需求生成一个自包含 HTML。
保存到 H5 分享仓库的 pages 目录。
更新首页目录数据，写清标题、描述、分类和日期。
推送到 GitHub Pages，返回公网访问链接。
